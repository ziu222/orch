# orch

Personal multi-agent orchestrator: one CLI and a local web console that drive Claude Code, Codex CLI, Gemini CLI and local Ollama models through your existing subscriptions. Task dependency graph, 5h/weekly usage per vendor, account-safe rate caps, cross-model code review.

Status: design and planning. See `docs/superpowers/plans/` for the engine + CLI plan and `orch-ui.html` for the UI prototype (sample data).
